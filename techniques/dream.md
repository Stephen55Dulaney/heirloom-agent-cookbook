# Technique: Dream — reducing the stock

> Nightly consolidation. Through the day, thoughts pile up in the durable capture log. Dreaming
> reduces them into the living memory — like a stock reduced overnight into something rich
> enough to cook with tomorrow. Mirrors how brains consolidate memory during sleep.

## The move
1. **Find the last consolidation date** in the living memory (`Last Updated:`).
2. **Pull everything newer** from the durable capture log.
3. **Append a dated section** to the living memory: one bullet per thought, first sentence or
   two, keep the tags and names so future searches work. Group by day.
4. **Stamp the date** — update `Last Updated:` to today.
5. **Capture the dream itself** back to the log ("dreamed N thoughts, themes: X, Y, Z").

## Done when
The living memory is current through today, and tomorrow's wake will find everything without
re-living it.

## The honest scar
This technique exists because one kit's living memory silently drifted seven weeks while the
capture log stayed current. The log saved everything — but only because reflect had kept writing
to it. Dream is the backflow that makes sure the two never drift apart again.

## Never
- Never overwrite — dreaming only appends. It must be safe to run twice.
