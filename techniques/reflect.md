# Technique: Reflect — tasting as you go

> Run at the end of a significant work session, while it's fresh. The session log on disk can
> die with the context window; reflection writes the day's learning somewhere that survives.

## The move
1. **Look at what actually happened** — the diffs, the files touched, what shipped, what broke,
   what surprised you. Evidence, not vibes.
2. **Write a session log** (a dated file): summary, what shipped, what was discovered, decisions
   made, what's next. Short session → short log. No filler.
3. **THE LOAD-BEARING STEP: capture a dense summary to the durable store** — 2–4 sentences with
   dates, numbers, paths, and the single most important insight. This is what future-you reads
   on wake. The on-disk log is nice; the durable capture is survival.
4. **Promote real lessons** — anything that should change behavior permanently goes into
   persistent memory or into the technique/skill card it improves.

## Done when
The session log exists AND the durable capture is written. Both, always — the second one is the
one that auto-reboots.

## Never
- Never skip the durable capture because the session "wasn't important." Drift starts there.
