# Technique: Sleep — closing the kitchen

> The bookend to wake. One command that closes the day properly: reflect first, then dream, then
> lights out. Bundling them means the day never goes unconsolidated because someone was tired.

## The move
1. **Reflect** (see [reflect.md](reflect.md)) — capture the session to the log FIRST, so
   tonight's work is in the durable store before consolidation.
2. **Dream** (see [dream.md](dream.md)) — consolidate the log into living memory, tonight's
   session included.
3. **Close out in a few lines** — what was reflected, how many thoughts were dreamed, and that
   tomorrow's wake will find it all.

## Why the order matters
Reflect feeds the log; dream drains the log into memory. Reverse them and tonight's session
misses the consolidation — the exact drift this whole loop exists to prevent.

## Never
- Never start new work inside sleep. Capture, consolidate, done. The kitchen is closed.
