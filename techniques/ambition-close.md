# Technique: Ambition Close — counting the plates

> The evening reconciliation: compare what you *said* you'd cook this morning against what
> actually left the kitchen. The rule that makes it honest came from a colleague's offhand
> remark — *"don't read the commit messages, read the diffs; just compare the two codes."*
> Messages are opinion. Diffs are fact. Whatever your day's work leaves behind — file changes,
> documents, sent messages, a capture log — *that* is the ground truth, not your memory of
> being busy.

## The move
1. **Pull the morning plan** — today's [`ambition`](ambition.md) file. If there isn't one,
   stop; you can't reconcile against a plan that doesn't exist.
2. **Pull the evidence** — the day's actual residue. For a builder that's the day's diffs
   across every active project; for anyone it's the trail of artifacts the day left behind.
   Read the *changes themselves*, not the labels someone put on them.
3. **Match plan to evidence, semantically.** Each morning ambition gets exactly one verdict:
   - **HIT** — planned, and the evidence shows it happened.
   - **PIVOT** — you worked the area, but the work that happened is different from the work
     you planned. Name what changed and why.
   - **MISS** — no evidence. Say so plainly. A miss recorded honestly is data; a miss dressed
     up as progress is rot in the memory.
   - **BONUS** — real work in the evidence that was never on the plan. Unplanned ≠ unimportant;
     bonuses often reveal what the day actually demanded.
4. **Credit the collaborators.** If agents co-produced the work and the evidence says which
   (attribution lines in the artifacts), note the human-to-agent ratio. Over months this tells
   the true story of how the partnership is evolving.
5. **Write one recommendation for tomorrow** — a single sentence, specific, placed where
   tomorrow's ambition will read it first. This is the loop closing: the close feeds the plan.
6. **File it** — verdicts, evidence pointers, completion rate, recommendation — into the same
   dated file as the morning plan, so each day is one document: intention on top, truth below.

## Done when
Every morning ambition has exactly one verdict backed by pointable evidence, bonuses are
recorded, and tomorrow's single recommendation is written where tomorrow will trip over it.

## Never
- Never grade from memory or from labels — if the evidence doesn't show it, it's a MISS, even
  if you're sure you did it.
- Never skip the close on a bad day. The 33% days are the ones that teach; the feedback loop
  only corrects behavior if the ugly number gets written down.
- Never let the recommendation be generic ("keep going!"). One specific, actionable sentence,
  or none.
