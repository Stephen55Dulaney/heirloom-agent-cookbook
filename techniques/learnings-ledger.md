# Technique: Learnings Ledger — the sauce that thickens

> Sessions end; lessons shouldn't. The ledger is one file where hard-won patterns go to
> survive their discoverer's next context death — each entry dated, evidenced, and scored for
> confidence. It's the difference between a kitchen that has cooked for years and a kitchen
> that has cooked one year many times.

## The move
1. **Capture at the moment of scar tissue** — when something breaks, surprises, or finally
   works, the `/reflect` at session end writes a candidate entry. Not a diary line — a
   *pattern*: the reusable rule the experience taught.
2. **Write the entry in four parts:**
   - **Pattern** — the rule, stated so a stranger could apply it. ("Names lie. Trust env
     wiring, not naming.")
   - **Context** — when it applies, and when it doesn't.
   - **Evidence** — a link to the session log, file, or artifact where it happened. No
     evidence, no entry.
   - **Confidence** — a number out of 10, written down. This is the part everyone skips and
     the part that makes the ledger honest: a 6/10 hunch and a 10/10 law must not dress alike.
3. **Date it and append** — the ledger is chronological, one file, plain markdown. Newest
   entries carry the freshest scars.
4. **Revisit confidence when evidence arrives** — a pattern that survives a second, different
   project earns a point; one that fails loses two and says why. Move the number, don't
   rewrite history.
5. **Let learnings travel** — periodically (or via a conductor agent, if you run one), ask:
   *which entries apply to a project that hasn't heard them yet?* A lesson trapped in the
   project that taught it is only half-learned.

## Done when
The ledger has entries a stranger could act on, every entry cites evidence, every confidence
number is a considered judgment — and at least once, an old entry has saved you from
re-learning something the expensive way.

## Never
- Never write an entry without evidence. Uncited wisdom is just mood.
- Never inflate confidence to make the ledger look wise. A ledger of honest 6s outperforms a
  ledger of performed 9s.
- Never bury it in a folder per project. One ledger, one life — patterns don't respect
  project boundaries, and neither should their storage.
